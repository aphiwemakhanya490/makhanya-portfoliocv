# Aphiwe Makhanya — Portfolio Website

A personal portfolio website built with **React** and **Vite**, showcasing my projects, technical skills, education, work experience, and professional background as an Information Systems & Technology graduate.

## 📌 About

I'm a **BCom Information Systems & Technology graduate** from the **University of KwaZulu-Natal (UKZN)**, graduating in 2025.

I have an interest in **software development, databases, web technologies, and emerging technologies**. My academic and personal projects have given me practical experience in developing applications, working with databases, designing user interfaces, and solving real-world problems through technology.

- Software development projects
- Work experience
- Professional competencies
- Contact information and CV

## ✨ Features

- 📱 Responsive design for desktop, tablet, and mobile devices
- 🧭 Multi-page navigation using React Router
- 💻 Project showcase with GitHub repository links
- 🎓 Education and academic achievements
- 💼 Work experience section
- 🛠️ Technical skills and competencies
- 📄 Downloadable CV
- 📧 Contact form integration
- 🎞️ Scroll and reveal animations
- 🔗 Social and professional links
- 🚀 Deployed on Netlify
- 🔄 Continuous deployment through GitHub and Netlify
